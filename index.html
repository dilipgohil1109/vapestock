📷 Catalog Images — Setup Guide

    
Follow these steps once to set up product images for the B2B catalog. Images appear in the catalog PDF when you add their Drive URL in the brand settings.

    
    

      
Step 1 — Create the images folder in Google Drive

      

        My Drive/

          KrazyStock_Data/  (already exists)

            catalog_images/  (create this folder)
      

    


    

      
Step 2 — Upload images with exact filenames

      
Each image must be named exactly as shown below. Format: JPG or PNG. Recommended size: 400×400px or larger, square crop.

      

    


    

      
Step 3 — Get the direct image URL

      

        1. Right-click the image in Drive → Share → set to Anyone with the link

        2. Copy the link — it looks like:

        https://drive.google.com/file/d/FILE_ID/view

        3. Convert to direct URL by replacing the end:

        https://drive.google.com/uc?id=FILE_ID

        4. Paste this URL into the brand's Image URL field (coming soon in Catalog tab)
      

    


    

      
Step 4 — Test it

      
Go to Export tab → Generate B2B Catalog. If the image URL is correct and publicly shared, the brand photo will appear in the catalog PDF.
